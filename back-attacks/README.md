# Back Attacks — Enter The System

Notes from John Danaher's *Back Attacks: Enter The System* (8 volumes). Like `triangles/`, these volumes were recorded as long combined videos — each contains several chapters back-to-back with no markers in the file. Chapter boundaries below follow the official chapter list from the course's own DVD case.

Each lesson has two versions:
- **Detailed** — full write-up with sections and a Key Takeaways summary.
- **Quick** — terse, numbered/checklist version for fast review before rolling.
