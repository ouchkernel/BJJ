# Kimuras — Enter The System

Notes from John Danaher's *Kimuras: Enter The System* (8 volumes). Like `triangles/` and `back-attacks/`, these volumes were recorded as long combined videos with no in-video chapter markers. Unlike those two, this course has no official DVD case chapter list to follow — the lesson boundaries and titles below were inferred directly from the transcript content (where a natural teaching point begins and ends), then organized into volume groupings that summarize each volume's focus.

Each lesson has two versions:
- **Detailed** — full write-up with sections and a Key Takeaways summary.
- **Quick** — terse, numbered/checklist version for fast review before rolling.
