# Defining The Single Leg Down On The Mat — Quick Reference

## Definition

- **Single leg down on the mat** = BOTH athletes on their knees.
- If either athlete is still standing → that's "standing position," not this — covered separately later.

## Why it matters

- Most jiu-jitsu happens on the floor, so this comes up constantly.

## Common ways it happens

1. Grappling on knees, opponent shoots straight in for a single leg.
2. Opponent in seated butterfly guard → pushes you back → shoots in for single leg.
3. Opponent on half guard bottom → gets underhook → comes up to knees → single leg.
4. Opponent in bottom pin/side control → gets underhook → spins up to knees → single leg.
