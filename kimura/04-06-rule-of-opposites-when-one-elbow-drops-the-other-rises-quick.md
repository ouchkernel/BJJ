# Rule Of Opposites — When One Elbow Drops, The Other Rises — Quick Reference

## The problem

- Elbow penetration needs an elevated elbow. Smart opponent drops the targeted elbow to the floor to kill it.
- Common failure loop: attack left elbow → opponent drops it → reset → attack left elbow again → fails again (tunnel vision).

## The rule

**As one elbow goes down, the other must rise.** Guaranteed mechanical fact — not optional for the opponent.

## How to use it

1. In north-south, both elbows are available — you don't pick which one gets defended, the opponent does.
2. Attack an elbow (either one).
3. If opponent defends by dropping it → the opposite elbow is now elevated.
4. Immediately switch your attack to that elbow instead of repeating the failed side.
5. Once the new elbow is elevated: hand behind the back if possible → elbow to the floor → step forward into a strong finish.

## Reminders

- You only need ONE elevated elbow — doesn't matter which.
- Don't tunnel-vision on a single arm — there are always two elbows in front of you in north-south.
- Elbow goes down on one side → don't force it, switch sides.
